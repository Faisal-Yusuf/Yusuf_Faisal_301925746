# FAHAJ NoSQL Database Implementation

## 1. Project Overview

This portfolio demonstrates the application of NoSQL database technology to FAHAJ, a proposed wristwatch manufacturing and distribution company.

FAHAJ manufactures standard wristwatch models and also produces customised watches based on customer specifications. Its operations involve managing watch models, customer orders, inventory, suppliers, warehouses and distribution.

## 2. Database Technology

- **Database:** MongoDB Community Server
- **MongoDB version:** 8.0.38
- **Database name:** FAHAJ
- **Collection implemented:** WatchModels

The MongoDB environment was started and accessed through the MongoDB Shell (`mongosh`).

The existing FAHAJ database and `WatchModels` collection were verified. A sample document, `FAHAJ Classic`, was successfully retrieved, demonstrating that the collection contains accessible watch model data.
